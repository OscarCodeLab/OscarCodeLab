## 🚀 About Me 
I'm a QA Engineer transitioning into data analytics, with 3+ years of experience working remotely on payment, onboarding, event, and messaging workflows at Chasescroll.

QA taught me to break things on purpose to find what's wrong. Now I do the same with data — currently turning a messy multi-table retail dataset into a Power BI dashboard, alongside SQL and Excel projects.

When I'm not working with data, I enjoy exploring new tech and listening to music. I love the "aha!" moment when data reveals something new and useful.
